## 关于 FlowMind

FlowMind 是一个 AI Native RPA 编排系统，将 RPA 的自动化能力与 AI 的自然语言理解相结合，通过 MCP 协议实现标准化的工具连接。

**项目特点**：
- 自然语言驱动的流程自动化
- 插件化架构，易于扩展
- MCP 协议，标准化工具连接
- 本地执行，数据安全
- 多用户权限隔离
