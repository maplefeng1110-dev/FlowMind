账号权限中心

新建业务账号

管理员创建账号后，可以立即给它分配不同的 RPA 插件。

新账号默认角色为业务账号。
插件接入向导

把现成 Python RPA 文件快速包装成插件，或直接生成空白骨架。生成后会自动写入 manifest 元数据，重启 Agent 即可上线。

填写插件 ID 即可开始；如果提供 Python 文件路径，系统会优先按现成实现生成 wrapper 与 manifest。若要按机器安装，请先确保目标 Agent 已配置 `AGENT_ADMIN_PUBLIC_URL`，并为 Web 服务配置对应机器的管理 token。
插件授权

管理员默认拥有全部插件权限；业务账号按下方勾选结果生效。
